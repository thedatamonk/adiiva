# ADIIVA Voice AI Gateway

A high-concurrency, multi-user Voice AI Gateway built with Pipecat, FastAPI, and Redis.

## Quick Start

```bash
git clone <repo-url>
cd adiiva
cp .env.example .env
# Fill in your API keys in .env
./start.sh
```

The script will auto-generate a `JWT_SECRET` and run `docker compose up --build`.

The app will be available at `http://localhost:8000`.

## Environment Variables

| Variable | Description |
|---|---|
| `DEEPGRAM_API_KEY` | Deepgram STT API key |
| `OPENAI_API_KEY` | OpenAI LLM API key |
| `CARTESIA_API_KEY` | Cartesia TTS API key |
| `JWT_SECRET` | JWT signing key (auto-generated by `start.sh`) |
| `REDIS_URL` | Redis connection URL (set automatically in Docker) |
| `MAX_CONCURRENT_SESSIONS` | Max concurrent sessions per user (default: 2) |

### Seed Users

The app comes with pre-configured demo users for testing. Use the `/token` endpoint to obtain a JWT.

## Architecture

- **FastAPI** — HTTP + WebSocket server
- **Pipecat** — Voice AI pipeline (STT → LLM → TTS)
- **Redis** — Session state, rate limiting, concurrency control
- **Docker Compose** — Single-command deployment (app + Redis)

## API Endpoints

| Endpoint | Method | Description |
|---|---|---|
| `/` | GET | Web client |
| `/token` | POST | Issue JWT token |
| `/ws/talk` | WebSocket | Voice AI session (requires JWT) |
| `/health` | GET | Health check |
| `/metrics` | GET | Usage metrics |

## Development

To run locally without Docker:

```bash
# Start Redis
docker compose up -d redis

# Install dependencies
uv sync

# Run the app
uv run uvicorn src.app:app --host 0.0.0.0 --port 8000
```

When running locally, use `REDIS_URL=redis://localhost:6379` in your `.env`.
